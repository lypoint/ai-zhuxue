# 图片一期部署与验收

本期实现图片提问、程序绘图、生图及图片复核；语音、朗读属于二期。

## 部署顺序

1. 安装 `server/requirements.txt`，设置稳定的 `LLM_KEY_SECRET`，不得随重启变更。新模型密钥和任务快照使用 Fernet 密文；兼容读取历史 `encv1` 签名凭据，编辑保存时升级。已有密钥不会被批量改写。
2. 在七牛创建**私有** Kodo Bucket，绑定 HTTPS 下载域名，或使用官方虚拟主机式 S3 HTTPS 域名 `https://<bucket>.s3.<region>.qiniucs.com`（例如浙江为 `cn-east-1`；应用按 Signature V4 签名，Bucket 名必须匹配）。七牛默认测试域名未必具有匹配的 HTTPS 证书，不可关闭 TLS 校验。配置 `server/.env.example` 中 `QINIU_*`；上传域名必须匹配 Bucket 区域。开通图片内容审核，保证服务端能访问审核接口和存储域名。
3. Web 构建须在七牛为实际站点设置 CORS，上传端允许 POST/OPTIONS 和必要的 Content-Type 请求头，下载端也须允许该 Origin 的 GET/HEAD（Flutter Web 的图片渲染需要 CORS）；服务端 API 也须允许该站点。原生请求不依赖浏览器 CORS。
4. 安装包含中文及目标教学语言字形的字体，设置 `IMAGE_FONT_PATH`。缺少字形的程序图不应上线。
5. 备份数据库，运行 `alembic upgrade head`（生产启动也会迁移）。迁移兼容无图片历史消息；图片数据非空时拒绝降级，防止静默丢失。
6. CMS 新建读图/生图配置，测试、启用，然后到老师的“图片能力”绑定。最后设置 `IMAGE_FEATURES_ENABLED=true` 并重启。默认关闭。

### Docker Compose 配置（2026-10-23 同步）

当前 `docker-compose.yml` 已向 API 传入 `IMAGE_FEATURES_ENABLED`、`QINIU_ACCESS_KEY`、`QINIU_SECRET_KEY`、`QINIU_BUCKET`、`QINIU_DOMAIN`、`QINIU_UPLOAD_URL`、`QINIU_CENSOR_URL`、`IMAGE_MAX_BYTES`、`IMAGE_MAX_PIXELS` 和 `IMAGE_FONT_PATH`。把实际值放在部署机私有环境或 Compose `.env`，不要写入 Git。

字体目录通过 `${IMAGE_FONT_DIR:-/usr/share/fonts}:/usr/share/fonts:ro` 挂载。`IMAGE_FONT_DIR` 是宿主机目录，`IMAGE_FONT_PATH` 是容器内文件路径，默认为 `/usr/share/fonts/opentype/noto/NotoSansCJK-Regular.ttc`；宿主机必须实际安装该字体，挂载本身不会安装字体。自定义目录时相应调整容器内文件路径。先确认字体文件可读，再按上述顺序启用功能；不在日志中输出含存储密钥的完整 Compose 配置。

既有 systemd 部署不会读取 Compose `.env` 或其挂载，须按私有生产说明将同一组应用配置加入服务实际加载的环境文件，并在服务主机上提供字体。发布时保留现有加密密钥，先备份、更新依赖和迁移，再重启与验收；不得把 Docker 命令用于替换现有部署方式。

## 存储与访问

上传凭证限制 Key、10 分钟有效、不可覆盖。图片先进入 `incoming/`，服务端检查实际格式、字节数、像素数，按 EXIF 方向旋转，剥离元数据并重新编码到 `private/`。仅接受 JPEG/PNG/WebP，默认单张 8 MiB、2000 万像素、每条消息 3 张；移动端选择器先缩至 2400 像素范围。

安全审核失败或服务不可用时不开放图片。学生与同家庭家长通过鉴权接口获取 5 分钟签名 URL，数据库不存临时 URL。撤销设备后不能签发新 URL，已签发链接在有效期内仍可读取。必须在七牛控制台确认 Bucket 私有属性，应用无法替代此设置。

未绑定附件、失败输出及原始上传对象在 24 小时后清理。删除孩子/注销账号时保留删除标记，后台重试七牛对象删除。家长会话、收藏、导出包含附件 ID；导出不是离线图片归档，访问图片仍需鉴权。

## 模型协议

| 用途 | 协议 | API 根路径示例 | 请求 |
|---|---|---|---|
| 独立读图 | `openai` | `https://dashscope.aliyuncs.com/compatible-mode/v1` | `/chat/completions`，多模态输入、JSON 输出 |
| 兼容生图 | `openai` | 供应商兼容根路径 | `/images/generations`，单张 1024×1024，接受 URL 或 `b64_json` |
| 多模态生图/编辑 | `dashscope` | `https://dashscope.aliyuncs.com/api/v1` | `/services/aigc/multimodal-generation/generation` |
| 万相异步生图 | `dashscope-wan` | 同上 | `/services/aigc/text2image/image-synthesis`，轮询 `/tasks/{id}` |

具体模型 ID 必须是账号和地域已开通、支持该协议的型号。2026-10-20 本账号实测可用读图型号为 `qwen3-vl-plus`，`qwen-vl-plus` 返回不可用；万相 `wanx2.0-t2i-turbo` 实际调用成功。以上两个已验收的千问主模型 `qwen-plus`、`qwen3-vl-plus` 在阿里云北京兼容端点按最高 32768 个输出 Token 发送，其他供应商与型号保留原请求上限。无预置、无自动切换供应商。七牛提供兼容端点时也可配置；图片存储始终使用七牛。

生图 URL 仅接受 HTTPS、无跳转、公开地址，域名限 `.aliyuncs.com`、`.qiniucdn.com`、`.qiniu.com`、`.qiniuapi.com`。其他供应商可使用 `b64_json`，否则须补充经核实的域名和适配。兼容协议未包含参考图编辑、流式生图、自定义尺寸；参考图编辑须选择支持该能力的 DashScope 模型并勾选。JSON、参考图格式和模型权限以 CMS 实测为准。

独立读图价格单位为元/百万 Token，生图为元/输入张、元/输出张。日志为估算；主模型规划/原生读图未配置独立价格，当前记录为 0；CMS 测试费用须查供应商账单。因此日志合计不能作为实际账单。

修改配置会增加版本、禁用，须重新测试启用。主模型读图测试签名包含地址、模型、密钥，修改后原测试失效。输出图片必须配置可用读图复核模型，或通过主模型读图测试。

## 运行机制

学生只选老师，入口按老师当前能力显示。图中题干、关系和不确定部分先识别，再经过学习围栏；图片指令视为学生材料。原生模式同时给主模型原图，辅助模式传识别材料。

老师可自动按需配图，学生也可点“配图讲解”。文字先完成，图片异步补上。规划仅返回受约束 JSON，不执行模型代码；精确关系用程序绘图，普通插画调用生图 API。安全审核和读图一致性复核均通过才发布，准确率仍须题库与人工评估。

每条消息只有一个任务，重复请求复用；失败/自动跳过后可人工请求。每日图片次数独立限制，不增加提问次数；新配图受订阅、休息时段和使用时长限制。任务使用数据库原子抢占，多 API 进程可并行工作。

运行超过 15 分钟标记失败供手动重试；结果未知时不自动重发付费调用。万相任务 ID 仅保存在当前执行过程；进程重启无法保证取回未知供应商结果，需核对账单再决定是否手动重试。

## 上线联调

自动化回归使用模型/存储替身。历史隔离环境的阿里云/七牛联调不能代替本次发布验收，实际验收材料由部署方在仓库外保管；移动端真机与生产环境仍需按下列清单确认：

1. 七牛私有权限、HTTPS、上传区域、CORS、真实审核服务及异常关闭访问。
2. CMS 探针、绑定老师、修改后失效、原生/辅助读图、三种生图协议及参考图编辑。
3. Android/iOS 真机首次授权、拒绝后恢复、拍照/相册、仅图片发送、上传失败重试和放大。
4. 手写/模糊/公式/多图识别；数轴/几何图标签和关系；插画复核；失败保留文字。
5. 跨家庭、设备撤销、家长审查、签名到期、删除孩子后对象清理。
6. 并发请求、任务中重启、供应商超时、每日限额、休息时段、长会话和费用核对。
