# 家长端与学生端多语言

支持简体中文 `zh-Hans`、繁体中文 `zh-Hant`、英文 `en`、日文 `ja`、韩文 `ko`、德文 `de`、西班牙文 `es`。

## 客户端

- 默认跟随设备系统语言；中文按字形或地区区分简体与繁体（台湾、香港、澳门默认繁体），其他地区使用对应基础语言，未支持的系统语言回退英文。
- 家长端登录页与首页、学生端绑定页与聊天页右上角提供语言按钮。手动选择保存到本机，退出登录保留；选择“跟随系统”清除覆盖设置。
- `app_core` 提供 `AppLanguage`、`LanguageApp`、`LanguageButton`、`tr`，三个家长渠道壳共用同一套实现。SDK 初始化与账号恢复前加载翻译。
- 固定界面文案及参数化提示保存在 `app/app_core/assets/i18n/catalog.json`，7 份词典随包离线发布。Flutter Material / Cupertino 系统控件也使用对应语言。
- `tr(source, args)` 按 `{0}`、`{1}` 插入数据，支持不同语言调整词序；修改文案时同步更新全部词典并保持占位符一致。页面 `build` 调用 `AppLanguage.watch(context)`，已打开的页面随语言变化重建，输入与会话状态保留。
- `trMessage` 只用于服务端系统通知、错误和系统生成的评估描述，按已登记的模板转换，并保留动态参数。`ApiException.rawMessage` 用于状态判断，`message` 用于显示；不能按翻译后的字符串判断业务状态。
- 用户昵称、题目、聊天历史、人工回复与自定义老师名称保持原文。微信、商店及运营商授权页的文字由提供方控制；选择语言不改变手机号核验地区、业务计费币种或账号权益。

## 老师回复

`POST /chat` 与 `POST /chat/stream` 的请求体新增 `locale`，每次发送取当前客户端语言；同时客户端请求发送 `Accept-Language`。正式回复以请求体的语种为准，不依赖家庭上一次使用的语言，也不从问题文字自动猜测。没有 `locale` 的旧客户端继续使用简体中文。

服务端把语种归一到受支持的枚举，再写入固定的系统指令。解释、标题、引导和追问使用当前语种；代码、公式、引用和语言教学例句可保留其必要的原始语言。历史消息不翻译，也不重新生成。一次请求采用发送时的语种，切换语言后的下一条请求使用新语种。

输入拦截、家长禁用词拦截、输出安全复核后的替代话术均有 7 份固定翻译。分类器的输出字段仍为内部英文枚举；规则降级模式补充各语种的常见学习及危险内容信号，不能替代模型的完整语义安全分类。

兼容地区标签如 `zh-CN`、`zh-TW`、`en-US`、`ja-JP`、`es-MX`；不支持的语种返回 422。客户端传入值不直接拼接为模型指令。

## 验证与维护

共享核心测试检查词典完整性、全部占位符、地区/字形匹配、偏好保存、语言切换时保留输入，以及普通/流式请求的语种。家长和学生根组件逐个验证 7 种语言。服务端测试验证两种聊天接口的语言指令及安全替代话术。

词典初稿采用机器翻译，并校订主要导航和操作术语；上线前需做各语种母语校对。模型测试使用受控响应，真实模型的措辞、字形和安全表现还需按语种验收。
