# 产品路线图（M0–M3）

**锚点**：立项评审「附条件推进」+ 窗口收窄判断（豆包 2025-08 上线未成年人模式，C21/C35）→ 节奏原则：**先闭合合规委托，再扩功能**。里程碑时间待提案方补齐团队/预算后确定。

## M0 生产骨架 ✅（2026-09-17 完成）

- 双端 Flutter + FastAPI + Postgres 全链路跑通（含模拟器真机验证）；
- 围栏四阶段管线 + 流水落库 + heuristic/llm 双模式；
- 三要素核验接口（mock）、绑定码、家长全量审查、时长管控；
- 题库样例 + 评测脚本 + docker-compose。

## M1 内测版（合规委托回复后启动）

**工程先行部分（2026-09-17 已实现，无需等外部凭证）**：Web 端（仅聊天）、审查数据导出（条例 34）、学生注销/硬删除（个保法）、API 限流、题库扩充至 69 题 + 对抗组 8 题、评测 `--check` 阈值退出码（CI 可断言）。

**触发条件**：法务意见 + 专利代理人意见到位（两份委托已发）。

- 围栏：`FENCE_MODE=llm` 全量启用；题库扩至每库 ≥300 题 + 对抗子集；评测达标（学习应答≥95%/误拦截≤5%/绕过≤2%）；
- 三要素核验真实接入（阿里云/腾讯云），按法务问题 2 结论叠加增强（实名支付绑定 / 人脸可选项）；
- Alembic 迁移、密钥入密管、API 限流、短信服务商接入；
- 家长审查导出（条例 34 复制权）；账号注销与数据删除（个保法）；
- 内测：20–50 个真实家庭，收集误拦截样本回流失效库。

## P0 商业与安全闭环（2026-09-19 完成）

产品评审（PM review）确定的两个上线前提已落地：

- **订阅付费闭环**：`subscriptions` 表（注册自动开 30 天试用）→ 到期拦截（学生端 402 + 引导文案）→ mock 支付顺延 30 天 → CMS 订阅统计（活跃/试用/到期/累计收入）。生产支付回调为外部依赖（商户资质）。
- **家长通知与安全告警**：`notifications` 表 + 四类事件（security/fence/quota/system）。敏感拦截即时告警（对标 Character.AI 诉讼"未告知家长"的教训）；fence/quota 同日去重防骚扰；家长端通知中心（未读角标/全部已读）。离线推送通道为外部依赖。
- **双端退出登录**（客户端清 token；服务端吊销在 M2）。

## P1 管控升级与学习摘要（2026-09-19 完成）

- 家长自定义禁用时段（`FamilySettings.quiet_*`，覆盖全局、可整体关闭），替代写死 22–6；
- 学习摘要 `GET /parent/students/{id}/summary`：今日/本周提问数、拦截数、引导数、估算活跃时长（消息时间跨度法，单日上限 60 分钟）、本周活跃天数——家长端审查页顶部一屏掌握；
- 指南时长管控完整要求对齐：**真实使用时长已实现**（端侧 60s 心跳上报 → ActiveTime 累计 → 时长上限拦截 + 摘要真实分钟数；防刷单次≤120s/日≤6h）。

## P2 首批（2026-09-19 完成）

- **孩子学段设置**：家长端下拉切换（8-12/12-16/16-18），联动系统提示分龄与围栏预期——分龄差异化的开关已打开（内容池分龄待 M2 扩展）；
- **学习沉淀最小版（收藏）**：学生长按消息收藏（快照、幂等），抽屉「我的收藏」回看（Markdown/LaTeX 渲染），家长可见（只读，了解兴趣点）；
- **新用户引导**：试用期内且未绑定孩子时，家长端首页展示三步引导卡（可关闭）。

## M2 技术债首批（2026-09-19 完成）

- **JWT 吊销**：`token_version` 机制 + `POST /auth/logout`，登出/注销后旧 token 立即失效（此前"客户端清除"是诚实但不够的安全态）；
- **生成侧内容安全复核**：assistant 全文输出后二次分类（TC260 生成合格率的工程保障），sensitive → 落库替换 + security 告警；流式已送达部分无法撤回已在 api.md 诚实声明；
- **审查内容搜索**：`GET /parent/students/{id}/search`（标题+全文），家长端审查页搜索框直达。

## 围栏真实验评达标（2026-09-19）

用 OpenRouter（deepseek-chat-v3.1）跑 `FENCE_MODE=llm` 全量评测：四项指标全部过线（学习应答 100%、娱乐改写 100%、敏感拦截 100%、对抗拦截 100%）。**围栏从"工程实现"进入"验收达标"状态**——剩余差距仅题库规模（69+8 → 每库 300，教研任务）。Web XSS 缺口同日修复（DOMPurify 消毒 LLM 输出渲染）。

## 已提前落入 M1/M2 的能力（2026-09-19）

- **CMS 管理后台**（M2 计划提前完成）：`/cms` 运营看板（规模/活跃/围栏分布/成本）+ LLM 分组配置（多分组、热切换、日上限、Key 引用）+ 家族列表（手机号脱敏）+ 围栏审计流；35 例测试。
