# 一期图片功能执行计划

范围：图片输入、图片讲解、七牛私有存储；语音输入和朗读留到二期。

## 步骤与验收

1. ✅ 数据与凭据：新增独立图片模型、私有附件、配图任务；老师引用读图/生图配置，兼容历史消息；使用 Fernet 加密新凭据并兼容旧格式读取。
2. ✅ CMS：管理独立读图/生图配置，区分协议、测试与启用；每位老师选择关闭/主模型读图/辅助读图，独立开启生图、精确绘图和自动配图。
3. ✅ 七牛：限定上传凭证、实际文件校验、去除元数据后转存不可覆盖对象；图片审核失败关闭访问；鉴权签名读取、孤立附件回收与删除重试。
4. ✅ 聊天：只接收附件 ID，读图内容进入学习围栏；复核后显示；配图计划使用受约束 JSON，精确图由程序绘制，插画调用生图 API；任务持久化、幂等、限额、配置快照、重启恢复。
5. ✅ Flutter：相机/相册选择、预览移除、失败保留、仅图片发送；图片放大、配图请求与任务恢复；家长审查、收藏、导出同步附件。
6. ✅ 本地验证：后端行为测试、迁移升级/降级、CMS JS 检查、Flutter analyze/test；补充运行配置与联调步骤。

## 约束

- 学生只选择老师，不接触模型和密钥。新请求遵循现有老师/渠道/订阅规则。
- 输入与输出图片最终均保存在七牛私有 Bucket；数据库只保存对象 Key，临时 URL 不持久化。
- 图片安全审核和学习围栏分别执行；未通过审核的图片不向学生展示。
- 配图失败不抹去文字回复；相同消息配图幂等，失败可单独重试。
- 供应商超时结果不明时不自动重复收费调用，任务标记失败供用户确认重试。
- 不自动写入真实密钥或调用付费服务。真实 API、七牛域名、图片质量和真机权限作为上线联调项目。
