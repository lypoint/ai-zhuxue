# AI 助学统一标志方案

## 核心设计

品牌统一使用“展开的书本 + 启发之星”：书本代表学习，星形代表引导和获得新理解。标志始终保持同一轮廓，不为老师角色、学生或家长分别设计独立图形。字标统一写作 **AI 助学**。

使用示意：[四端使用示意](logo-system.svg) · [透明底图形母版](logo-mark.svg)。App 图标源文件：[学生版](app-student.svg) · [家长版](app-parent.svg)。

## 四端使用

| 场景 | 标志 | 背景与名称 | 主要位置 |
| --- | --- | --- | --- |
| 学生 App | 图标白色、启动页青绿的同一图形 | 青绿 `#2F8B7D`；应用名“AI 助学·学生版” | iOS / Android 图标、启动页、绑定页 |
| 家长 App | 图标白色、启动页深蓝的同一图形 | 深蓝 `#253A68`；应用名“AI 助学·家长版” | iOS / Android 图标、启动页、登录页 |
| Web 学习助手 | 青绿同一图形 | 白底；导航栏“AI 助学”，浏览器标签页仅用图形 | 页头、favicon、PWA 图标（如启用） |
| CMS | 页头白色、favicon 青绿的同一图形 | 深蓝页头；“AI 助学 · 运营管理” | 登录页、页头、favicon |

老师头像是可配置的角色头像，不替换品牌标志；学生端和家长端的历史老师头像继续按会话快照展示。

## 制作与验收

- 维护一份无文字的 SVG 母版；App 图标、Web favicon 和页面图形均从母版导出，避免各端手工重画。
- 最小显示尺寸：favicon 16×16，页头 24×24；若书页或星形在 16px 模糊，应先简化母版。图标四周保留约 12% 安全边距。
- 导出学生、家长两套不带文字的 1024×1024 图标，分别生成 iOS 与 Android 所需尺寸；Android 另检查自适应图标遮罩裁切。不要在 App 图标里写“学生/家长”。
- 在浅色、深色和灰度背景检查可读性；学生与家长图标并排时应能靠底色和系统名称区分。
- 替换现有 Flutter 默认启动图标，并同步 Web/CMS 页头与 favicon；验收时检查桌面、应用商店、浏览器标签页及小屏页面。

已替换两款 App 的 iOS、Android 图标与启动页图形，以及 Web、CMS 的页头标志和 favicon。运行时 SVG 副本位于 `server/app/logo.svg` 与 `cms/logo.svg`；调整母版时须同步更新这两份文件及 App 导出图。

Android 构建最低版本为 API 23，这是当前安全存储依赖的要求。
