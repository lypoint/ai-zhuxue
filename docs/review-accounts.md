# 应用审核账号

所有渠道家长端提供“账号密码登录”，保留原有渠道登录方式。学生端也提供该入口，但只有受管理的审核账号可用密码直接登录；普通学生仍使用家长生成的一次性绑定码。

审核账号属于独立家庭，拥有 100 个学生名额的永久会员。家长端可管理家庭和体验所有会员功能；学生端首次密码登录按设备创建并绑定审核学生，同一安装重复登录复用学生。正常的内容安全和家长管控仍生效。账号不触发真实订阅扣款，永久会员不显示购买入口。

## 创建

在生产 API 相同环境和数据库配置下，先执行 `alembic upgrade head`，再运行：

```sh
python -m app.review_account create --credentials-file /private/credentials/reviewer.json
```

目标目录须已存在，凭据文件须位于公开项目目录外。命令生成小写英文与数字组成的账号密码，凭据文件权限为 `0600`；数据库仅存加盐 PBKDF2 密码哈希。命令不输出密码、不覆盖现有文件、不重新启用已存在账号。凭据不得写入本仓库、构建参数或应用资源。

审核说明可填写：“打开应用，选择账号密码登录，输入所提供账号和密码。无需验证码或第三方账号。账号已开通 100 名额永久会员。学生端使用相同凭据即可绑定到独立审核家庭。”应使用包含此入口的新版本包。

## 审核结束后停用

确认商店审核已结束后，在同一生产环境运行：

```sh
python -m app.review_account disable --username <审核账号>
```

此操作只接受受管理的审核账号，事务内停用整个家庭、撤销家长和学生会话、停用所有绑定学生、撤销学生设备及绑定码。新密码登录和绑定也被拒绝，其他家庭不受影响。重复停用安全可用；不会删除审核记录。

没有可信的商店审核完成回调，因此不按固定日期自动停用，避免中断仍在进行的审核。每轮审核完成后执行上述停用操作；后续审核另建账号。
