# 家长端共享库

此包提供共享界面与家庭业务，不含支付 SDK，也不直接打包。

执行入口为 `../app_parent_wechat`、`../app_parent_appstore`、`../app_parent_googleplay`。
当前通用流程见 [部署与运维](../../docs/deployment.md#4-flutter-构建产物)，正式包使用 `scripts/build_parent.py`。真实商店参数及密钥加载见仓库外的 [渠道订阅接入](../../../credentials/store-subscriptions.md)。

守护页按孩子分别保存消息／时长上限、休息时段和引导通知；家庭时区单独确认，日期展示、评估与成绩筛选均使用家庭口径。历史未设置时区的家庭使用 API 返回的旧偏移量，新旧接口配套更新；旧接口缺少该字段时兼容默认 UTC+8。

订阅卡区分注册试用、订阅试用及付款恢复状态。管理入口按已核验购买来源选择，同渠道商店保留恢复购买；Waffo／其他渠道权益不提供当前渠道升级。审查页可通过系统分享／保存导出孩子 JSON，通知支持分页及服务端未读筛选。国内官网继续只提供 App 服务，不恢复国内 Web。

新增系统文件分享复用 share_plus 10，时区换算使用 timezone 0.10；各渠道锁文件已同步，正式安装包按对应渠道分别验证。共享文案复用 Web 的 78 语种资源；少量 App 专用新提示覆盖七个基础语种，其余语种使用英文回退。

试用规则：国内手机号注册默认 30 天，Google 登录家庭注册 3 天。Google Play 符合资格的订阅使用商店原生 `P30D` 免费阶段，之后按正价月度续订；两段试用重叠、不补赠剩余注册试用。普通月价及试用后价格均读取商店最后付费阶段。真实 Play Console 优惠启用与许可测试步骤见 [当前支付规则](../../docs/parent-payment-packaging.md#当前试用规则2026-11-02)。
